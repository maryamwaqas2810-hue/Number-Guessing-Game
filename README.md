# 🎯 Number Guessing Game

A simple command-line game built with Python.

The computer generates a random number, and the player tries to guess it.

## 🎮 How It Works

1. The computer generates a random number.
2. The player enters a guess.
3. The program tells the player whether the guess is too high or too low.
4. The game continues until the correct number is guessed.

## 🛠️ Concepts Practiced

- Python basics
- Variables
- Input and output
- Conditional statements
- Loops
- Functions
- Random numbers
